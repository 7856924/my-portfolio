# Ravali Kommidi — Cybersecurity Portfolio

A responsive, single-page portfolio built with plain HTML, CSS and JavaScript.

## Publish with GitHub Pages

1. Extract this ZIP.
2. Open your `my-portfolio` GitHub repository.
3. Replace the existing site files with `index.html`, `style.css`, `script.js` and `Ravali_Kommidi_Resume.pdf`.
4. Commit the changes to the branch/folder configured in **Settings → Pages** (commonly `main` / root).
5. Wait for GitHub Pages to deploy, then refresh your portfolio URL.

## Files
- `index.html` — portfolio content and sections
- `style.css` — responsive dark visual design
- `script.js` — mobile navigation
- `Ravali_Kommidi_Resume.pdf` — resume download

## Before publishing
- Verify all dates, employer details, phone number and email.
- Keep only checklist activities you have genuinely reviewed or performed.
- Add repository links for other projects if you want them displayed.
